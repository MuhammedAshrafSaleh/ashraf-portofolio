The problem

EUX resells J&T Express shipping, but orders lived in scattered chats and spreadsheets.

The solution

A clean Arabic app with a full manifest, per-user orders, and signed live tracking.

Tech stack
Flutter
flutter_bloc
Firebase Auth
Cloud Firestore
Google Sheets
J&T Express API
Key features
01

Email/password auth (Firebase) with Firestore user profiles

02

Full J&T shipment manifest: receiver, address, COD/FOD, weight

03

Create, edit, delete & list orders — filtered per user

04

Live shipment tracking via the J&T Express API

05

Arabic translation of scan types & problem reasons

06

Google Sheets order backend via Apps Script Web App

Challenges I solved
01

Signed logistics API integration

J&T's tracking API requires HMAC-style request signing and returns raw scan codes.

02

A spreadsheet as a backend

With no dedicated server, a Google Sheet became the order database.
