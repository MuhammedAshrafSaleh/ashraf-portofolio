The problem

Finishing companies ran site cash on paper and WhatsApp.

The solution

A single multi-tenant app with three roles driven by JWT routing and Postgres RLS.

Tech stack
Flutter
Dart
Cubit
Supabase
PostgreSQL
Edge Functions
pg_cron
Key features
01

Multi-tenant role model: Owner / Admin / User with RLS isolation

02

Per-project cash ledger with vendor, amount, and date entries

03

Receipt capture (camera/gallery), compressed to ≤500KB

04

Branded PDF export with logo, entries, thumbnails & totals

05

Real-time notifications feed for admins

06

Seat-limited user creation via Supabase Edge Functions

Challenges I solved
01

Receipt image lifecycle

Storing every receipt forever was costly and risky.

02

One app, three panels, zero leaks

Owner, Admin, and User share one binary but must never see each other's data.
